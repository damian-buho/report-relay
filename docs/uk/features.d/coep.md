# Звіти Cross-Origin-Embedder-Policy

- Приймає звіти `coep`, і примусові, і лише для звітування, один запис на звіт.
- Назви `coep` та `coep-violation`, які вживали браузери, зводяться до одного типу, тож запиту не потрібно знати, яку з них надіслано.
