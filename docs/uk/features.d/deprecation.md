# Звіти про застарілі функції

- Приймає звіти `deprecation`, які показують, яку застарілу функцію браузера ваші сторінки досі викликають.
- Звіт без ідентифікатора й повідомлення відхиляється й рахується, тож кожен запис — такий, з яким можна щось робити.
