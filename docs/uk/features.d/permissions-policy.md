# Звіти про порушення Permissions Policy

- Приймає звіти `permissions-policy-violation`, давню назву `feature-policy-violation` та звіти `potential-permissions-policy-violation`.
- Звіт без ідентифікатора політики та стану відхиляється й рахується, тож запис завжди каже, яка політика спрацювала і чи була вона примусовою.
