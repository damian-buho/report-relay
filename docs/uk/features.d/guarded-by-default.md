# Публічна точка приймання, захищена за замовчуванням

- Усі обмеження увімкнені за замовчуванням: ліміт тіла, ліміт запитів на клієнта, білий список типів вмісту, обмеження глибини JSON і довжини масивів, а також перевірка схеми для кожного типу.
- Рядки запиту та фрагменти вилучаються з URL, які несе звіт, бо URL звіту часто містить токен; перемикач зберігає їх, коли потрібне повне значення.
- Ніколи не експортується нічого неперевіреного: звіт, який сервіс не може прочитати, рахується з причиною й відкидається.
- На preflight CORS для методів надсилання є відповідь, з необовʼязковим білим списком джерел; без налаштування підходить будь-яке джерело, бо надсилання міжсайтове за природою.
- За зворотним проксі пересланий ланцюжок враховується лише з довірених проксі-мереж (`REPORT_RELAY_TRUST_PROXY` плюс `REPORT_RELAY_TRUSTED_PROXIES`), тож прямий клієнт не може обрати власний ліміт-бакет підробкою заголовка.
