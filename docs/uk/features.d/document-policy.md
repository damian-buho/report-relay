# Звіти про порушення Document Policy

- Приймає звіти `document-policy-violation`, один запис на порушення.
- Звіт без ідентифікатора політики та стану відхиляється й рахується, тож запис завжди каже, яка політика спрацювала і чи була вона примусовою.
