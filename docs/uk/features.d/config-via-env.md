# Вбудовується без змін у встановлення OpenTelemetry

- Налаштування насамперед через середовище під `REPORT_RELAY_*`, а експортер читає стандартні змінні `OTEL_EXPORTER_OTLP_*`, тож власний блок клієнта не потрібен.
- Без налаштованого кінцевого пункту `OTEL_EXPORTER_OTLP_*` кожен запис іде до стандартного виводу як JSON, тож реле працює взагалі без збирача.
- Сервіс звітує про себе тим самим каналом: отримані, прийняті та відкинуті звіти, кожен відкинутий із причиною, що його спричинила.
- Структуровані JSON-журнали містять змінну за кожним рішенням, тож оператор читає з самого рядку журналу, чому звіт було відкинуто.
- Постачається як готовий бінарний файл для Linux на amd64, arm64 і riscv64 поряд з образом, тож працює на хості без середовища контейнерів.
