# Звіти про втручання браузера

- Приймає звіти `intervention`, які показують, коли браузер змінив вашу сторінку з міркувань продуктивності, безпеки чи зручності користувача.
- Звіт без ідентифікатора й повідомлення відхиляється й рахується, тож кожен запис — такий, з яким можна щось робити.
