# Тип звіту, який ще ніхто не визначив, усе одно зберігається

- Reporting API — це відкритий перелік, тож тип, якого ця версія ніколи не бачила, приймається з цілісним тілом, а не відкидається.
- Тип, непридатний для використання як мітка, потрапляє до групи `unknown`, а оригінальне написання відправника лишається в тілі запису.
