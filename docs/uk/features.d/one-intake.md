# Одна точка приймання для всіх звітів, які може надіслати сайт

- Усі формати зі списку надходять на одну точку приймання й маршрутизуються за типом вмісту, тож не треба розгортати окремий збирач для кожного типу звітів.
- Один POST перетворюється на один запис логу на звіт, готовий для стеку Loki, Tempo та Grafana, який у вас уже є: запит ніколи не бачить цілий пакет як один рядок.
- Кожен запис можна вибрати за його типом звіту та за сайтом, з якого він надійшов, тож дашборд фільтрує за `event_name` і `report.url_host`, не торкаючись рядка.
- Кожен формат має власний перемикач, тож приймання, яким ви не користуєтеся, можна відхиляти, поки решта працює.
