# Одна точка приймання для всіх звітів, які може надіслати сайт

- Приймає пакети Reporting API (CSP, COOP, COEP, збої, застарілі функції, втручання, цілісність, політики дозволів і документа, помилки мережі), старі тіла `report-uri` від CSP, старі звіти Expect-CT і HPKP, звіти SMTP TLS та інцидентні звіти CAA IODEF на одному endpoint, тож не треба розгортати окремий збирач для кожного типу звітів.
- Один POST перетворюється на один запис логу на звіт, готовий для стеку Loki, Tempo та Grafana, який у вас уже є: запит ніколи не бачить цілий пакет як один рядок.
- Кожен запис можна вибрати за його типом звіту та за сайтом, з якого він надійшов, тож дашборд фільтрує за `event_name` і `report.url_host`, не торкаючись рядка.
- Старе тіло CSP нормалізується до форми Reporting API, тож запиту не байдуже, який механізм використав браузер.
- Тип звіту, про який ця версія ніколи не чула, все одно доходить із цілісним тілом: Reporting API — це відкритий перелік, і новий тип не є причиною втратити звіт.
